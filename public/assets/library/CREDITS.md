# Crédits des modèles 3D de test

Ces six modèles servent uniquement à valider le pipeline d'assets. Ils proviennent tous du dépôt
officiel **Khronos glTF-Sample-Assets** (<https://github.com/KhronosGroup/glTF-Sample-Assets>).
Leurs licences autorisent la réutilisation, y compris commerciale. Pour CC-BY 4.0, il faut créditer l'auteur.

| Asset (id) | Fichier d'origine | Licence | Auteur(s) |
|---|---|---|---|
| `chair-damask` | ChairDamaskPurplegold.glb | CC-BY-4.0 | Eric Chadwick |
| `velvet-sofa` | GlamVelvetSofa.glb | CC-BY-4.0 | Eric Chadwick |
| `vase-flowers` | GlassVaseFlowers.glb | CC0-1.0 | Eric Chadwick, Rico Cilliers |
| `broken-window` | GlassBrokenWindow.glb | CC-BY-4.0 | Eric Chadwick |
| `milk-truck` | CesiumMilkTruck.glb | CC-BY-4.0 (logo Cesium : marque, non soumise au droit d'auteur) | Cesium |
| `cesium-man` | CesiumMan.glb | CC-BY-4.0 (logo Cesium : marque, non soumise au droit d'auteur) | Cesium |

Les fichiers `.glb` sont copiés sans modification. Les miniatures `thumb.jpg` sont des rendus de ces modèles
réalisés dans SQUA World Studio.

Page de chaque modèle : `https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/<Fichier d'origine sans .glb>`.
