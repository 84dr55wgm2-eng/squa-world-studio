# Plans de test (fixtures d'ingénierie)

Ces ScenePlans ont été **écrits à la main** (par Claude, pendant le développement, en suivant le prompt
système de `api/world.ts`) pour tester le World Composer sans appel à un modèle de langage.
Ils ne sont **jamais** présentés comme une génération IA dans l'application.

- `plan-cybercafe.json` — test A : « Petit cybercafé populaire à Lagos en 2002, 8 postes informatiques, ordinateurs CRT, comptoir près de l'entrée, murs usés et petite salle rectangulaire. »
- `plan-apartment.json` — test B : « Petit appartement moderne avec salon, canapé, table basse, télévision, plante et grande fenêtre. »
- `plan-street.json` — test C : « Petite rue résidentielle avec route, deux trottoirs, quatre bâtiments, quelques arbres, lampadaires et deux voitures. »
